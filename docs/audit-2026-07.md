## 修正した指摘

### gyo-119 — wrong (high)

- **問題**: answer が逆。国土交通大臣は「すべての宅地建物取引業者」に対して指示処分・業務停止処分をすることはできない。65条1項・2項により大臣が処分できるのは「その免許を受けた宅地建物取引業者」に限られ、知事免許業者に大臣が監督処分をする規定は存在しない。65条3項・4項は逆に「都道府県知事が、大臣免許・他県知事免許の業者で当該区域内で業務を行うもの」に処分できるという規定である。statement の「国土交通大臣はすべての宅地建物取引業者に対して」という文言は、監督処分ではなく71条(指導等=指導・助言及び勧告)の条文表現をそのまま流用したものであり、論点をすり替えている。
- **対応**: answer は false。国土交通大臣が指示・業務停止処分をできるのは自らが免許した業者のみ(65条1項・2項)。区域内で業務を行う他免許業者に対して処分できるのは都道府県知事(65条3項・4項)。「すべての宅地建物取引業者に対して」できるのは71条の指導・助言・勧告であって監督処分ではない。なお reference の「65条1項・3項」は指示処分のみの規定で、業務停止処分(65条2項・4項)を欠いており、引用としても不完全。
- **根拠**: 宅建業法65条1項〜4項、71条、71条の2 (https://laws.e-gov.go.jp/law/327AC1000000176)
