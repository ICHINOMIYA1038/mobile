# アプリアイコン制作のご依頼（AIとチャットしながら学ぶ宅建 - pAIrOf）

## アプリについて
- iPhone / iPad の学習アプリ。宅建士（宅地建物取引士）試験の全範囲を、**AI の先生とチャットで会話しながら**学ぶ
- 先生が論点を1つずつ説明し、選択肢や○×で確かめながら進む。過去問を解いて「なぜ？」と思ったら、その場で AI に聞ける
- 対象: 宅建の勉強が初めての社会人（20〜50代）。通勤やスキマ時間にスマホで少しずつ
- 同じ運営の Web サービス「pAIrOf 資格」（https://shikaku.pairof.jp）と同じブランド

## 伝えたいこと（優先順）
1. AI と「話して」学べる（チャット・会話・先生）
2. 宅建・不動産の試験の勉強である
3. 信頼できる・続けやすい（怪しい AI アプリ、子ども向けに見えない）

- 文字が多い・小さい文字（ホーム画面では約 60px で表示される）
