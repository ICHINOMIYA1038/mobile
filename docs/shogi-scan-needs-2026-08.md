# 将棋盤面スキャンアプリ ニーズ調査（一次情報）2026-08-28

`docs/market-research-2026-08.md` のT1（将棋: 盤面撮影→局面/棋譜）について、
知恵袋・ブログ・App Storeレビュー本文・技術文献から**生の声**を収集した結果。

## 1. ペルソナ別の生の悩み（出典付き）

### P1: 級位者・初心者 — 「リアル対局は振り返れない」
- 「対局後の感想戦で、盤面を正確に記憶できていないため、分岐点の局面に自力で戻せない。指導者は一瞬で並べ直せるのに」
  （[知恵袋 q13182864433](https://detail.chiebukuro.yahoo.co.jp/qa/question_detail/q13182864433)。回答は「チャンク式で覚えろ」等の**精神論のみ**＝ツールでの解決策が存在しない）
- 「ネット将棋では棋譜が残りますが、リアル将棋ではなかなか棋譜を残せません」（[なな夫のブログ](https://shogi-life.com/shogi-impression-game/2308/)。
  棋譜を覚えられるようになるのは強くなってから、という構造＝**弱い人ほど記録手段がない**）

### P2: 親将（子供将棋の親）— 「棋譜が取れるのは初段から」
- 「有段者になると、一局の対局を振り返って、棋譜をとることができるようになってきます」「負けた対局は棋譜をとってパソコンで解析して振り返るようにしました」
  （[じろうブログ・子供が初段を目指す勉強法](https://jiroblog5.com/子供が将棋初段になるために必要なこと？勉強法/)）
  → 棋譜による振り返りが上達法として確立している一方、**1級〜初段になるまでその手段が使えない**。子の対局を親が記録してあげたいニーズ。
- 親将コミュニティは[こども将棋情報室](https://kodomo-shogi.com/)（14年運営）等に集積。テーブルマークこども大会は全国規模（JT主催）で棋譜は残らない。

### P3: 定跡書・詰将棋本の読者 — 「本の局面をアプリに入れたい」
- 「将棋の定跡書をスマホアプリに簡単に入力でき、外出先でも確認したい」→ 回答は手入力アプリShogi Kifu（**iOS有料でも「買って損は無い」と購入**）
  （[知恵袋 q10275639330](https://detail.chiebukuro.yahoo.co.jp/qa/question_detail/q10275639330)）
- チェスでは同ニーズが**事業として成立済み**: [Chessvision.ai](https://chessvision.ai/) が本・PDF・動画の局面スキャンで **$5.99/月（$45.99/年）** のサブスク。iOS/Android/ブラウザ拡張展開、Best Chess Startup 2020。

### P4: 検討派 — 「実戦・中継の局面をAIにかけたい」
- 将棋スキャンLiteレビュー: 「保存した画像からの盤面解析をできるように。**将棋連盟liveの投了図からの変化を見たい**」（★3）
- ぴよ将棋レビュー: 「（戦型練習は）自分で局面を作成すればいいのだが、**いちいち面倒**」（★3）/「覚えておきたい手筋の局面を入力保存し…重宝」（★5）/「局面を作成する→反映すると持ち駒が消える」（★2、編集UIの品質不足）
- きふみAI（2026年・144件★4.6の新星）レビュー: 「**局面編集機能を追加していただくとさらに便利**」「編集のしづらさを感じる」「棋譜入力自体をきふみAIで出来るように」→ 最有力の検討アプリですら**入力・編集が弱点**と自認されている。

### P5: 発信者 — 局面図の作成・共有（ブログ・SNS・観戦記）
- 将棋局面図Maker（2026-02、評価1件）がこの用途専用に出たばかり。認識は外部Web API（えぬっくま盤面解析エンジン）依存。

## 2. 先行アプリの死因（将棋スキャンLite レビュー全文より）

2015年リリース・★2.1・放置。**着想自体はレビューで絶賛されている**:
> 「きちんと機能すれば**大儲けできる着想**のアプリだけに、ここで諦めてるのが残念」（★1）
> 「このようなアプリが**実際に存在して欲しい**と思わせるアプリでした」（★2）

死因（=品質バー）:
1. **認識精度**: 「盤面に歩が一枚であとは全部自陣の持ち駒に」「駒を認識しない」
2. **カメラ品質・権限バグ**: 「撮った画像の画質が悪くて読み込めない」「iPad Proでカメラアクセスが拒否された」
3. **課金設計の不信**: 「有料版を購入しないと棋譜が保存できません…優良誤認」「有料版を購入しても他のアプリがないと使えません」
4. **保存・再生動線の破綻**: 「局面保存したのに再生できない。どこに保存してるの！？」

## 3. 技術・市場の裏付け

- **精度は到達可能**: 東京農工大2019、スマホ撮影画像の局面認識で[99%超（DNN）](https://www.tuat.ac.jp/documents/tuat/outline/disclosure/pressrelease/2019/20190913_01.pdf)。
  それ以前の古典手法でも[マス認識97.0%・属性分類99.7%](https://jglobal.jst.go.jp/detail?JGLOBAL_ID=200902278479804427)。
- **プロの世界では既に自動化**: リコー開発の[将棋AI棋譜記録システム](https://jp.ricoh.com/technology/tech/118_shogi_ai)（天井カメラ動画→物体検知＋駒画像分類）。
  開発動機は「**記録係を担う人材が慢性的に不足**」。2021年にHEROZへ譲渡され「Kishin Eye」として公式戦運用。**アマ・個人向けは空白のまま**。
- **チェスで事業モデル実証済み**: Chessvision.ai（上記）。将棋には同等品が存在しない。
- 検討エンジン側は既に強い競合がいる（きふみAI: 水匠5相当のオンデバイス解析、買い切りPro）→ **エンジンで戦わず「入力層」を取る**のが正しい位置取り。

| 優先 | ニーズ | 証拠 | 技術難度 |

| 2 | **リアル盤面の写真 → 局面データ → AI検討/共有** | P1・P4の声、スキャンLiteの「存在してほしい」 | 中（農工大99%が根拠。駒の書体多様性が課題） |
| 3 | 局面図PNG生成・共有（P5） | 局面図Makerの存在 | 低（1の副産物） |
| 4 | **対局動画 → 棋譜自動生成**（P2親将・大会・教室） | リコーが法人向けに実証、アマ向け空白。「初段までは棋譜がとれない」 | 高（v2以降。三脚固定＋差分検知で段階的に） |

## 5. 企画への含意（MVP）

1. **入力3系統**: カメラ実盤 / 写真ライブラリ / スクショ（中継・本の局面図）。認識は**完全オンデバイス**（Core ML）・オフライン動作
2. **手修正UIを一級市民に**: 認識→9×9グリッド上でタップ修正→確定。誤認識前提の設計（スキャンLite死因1の保険）
3. **出口を全部つなぐ**: SFEN/BODコピー、.kif/.sfen書き出し、ぴよ将棋・きふみAI等で開く、局面図PNG共有 → 既存アプリと競合せず「入力層」として共生
4. **ライブラリ**: スキャンした局面の保存・タグ（詰将棋本の管理需要 = 将棋ログ/将棋ノートのユーザー）
5. **課金**: 無料=スキャン月N回＋全出口開放（保存人質はスキャンLiteの死因3）。Pro=無制限＋ライブラリ無制限＋（将来）連続撮影棋譜化。買い切り¥980〜1,480 or ¥300〜480/月。チェス相場は$5.99/月
6. v2で**「連続写真→棋譜」→「動画→棋譜」**（親将・教室・大会）。ここまで来ると国内唯一

## 6. 未検証・リスク

- 実盤の駒書体・彩光のばらつきでの実測精度（**着手前に技術スパイクで確認すべき唯一の項目**）
- 級位者がお金を払うか（P3のShogi Kifu購入例、きふみAIの買い切りPro、将棋ウォーズ課金文化は傍証）
- きふみAI（開発が活発・レビュー返信あり）が盤面撮影を先に実装するリスク → 出すなら早く
