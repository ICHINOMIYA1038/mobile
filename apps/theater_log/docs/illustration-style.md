# ゲキポンの挿絵の決まり（ゴム印の線画）

ゲキポンの挿絵は、もぎりのゴム印や切符の小さな記号のような線画で描きます。2026-11-08 にオーナーが 4 つの画風から選び、2026-11-09 に題材と色を広げました。描き手が変わっても同じアプリの絵に見えるよう、次の決まりを守ります。

## 決まり

| 項目 | 決まり |
|---|---|
| 題材 | 現代の舞台や小劇場で実際に見るもの（照明、受付、客席、アンケート、半券、チラシなど）。歌舞伎の道具は使わない（例外は提灯の列だけ） |
| 色 | 墨と朱が基調。差し色は柿・萌葱・金茶・生成り（`Palette.kaki`・`moegi`・`kincha`・`kinari`）。1 枚の中で差し色は 1〜2 色にとどめる |
| 線 | 墨の線 1 種類。120×100 の枠で太さ 2.2（細部は 1.2〜1.6）。角は立て、線の端は切りっぱなし |
| 形 | 直線と円・ゆるい曲線で、図のように整える。正面か真横から描く |
| 描かないもの | 人の顔、影、グラデーション、かすれ |

かすれはハンコだけの表現です。挿絵には付けません。挿絵とハンコが同じ画面に並んでも、どれがハンコかがすぐわかるようにするためです。

## 選び方

題材は「その画面で何をするか」がひと目で伝わるものを選びます。見本の判定では、意味が伝わらない絵（暗転、地下への階段、建物だけの劇場）は NG になりました。迷ったら、その画面の動作（探す・残す・集める・つながらない）をそのまま物で表します。

## 小さく置いたとき

画面に 44px で置いても形がわかることを確かめます。わからない場合は、細部を描き足すのではなく減らします。

## 作り方

- 絵は `lib/widgets/illustrations.dart` に描きます。見本ページと同じ SVG のパス文字列をそのまま書けます（`_Shape`）。
- 新しい絵は、先に見本ページで実寸の画面に置き、オーナーの OK をもらってからアプリに入れます。

## 使っている場所

| 絵 | 場所 |
|---|---|
| 幕が開く（`LineArt.curtain`） | 半券帳がまだ空のとき |
| 客席（`LineArt.seats`） | 「みんな」に感想がまだ無いとき |
| 舞台照明（`StageArt.light`） | ふりかえりの画面の上 |
| 懐中電灯（`StageArt.flashlight`） | 劇場や公演を探して見つからなかったとき |
| 受付のテーブル（`StageArt.reception`） | アカウント（ログインしていないとき） |
| 抜けたケーブル（`StageArt.unplugged`） | 「みんな」を読み込めなかったとき |
| 観劇のアルバム（`StageArt.album`） | 記録の手順「写真を残す」の見出しの横 |
| 劇場パスポート（`StageArt.passport`） | スタンプ帳の「劇場スタンプ」の見出しの横 |
| 提灯の列（`StageArt.lanterns`） | スタンプ帳のいちばん上 |
| アンケート用紙（`StageArt.survey`） | 感想を公開する前の確認 |
