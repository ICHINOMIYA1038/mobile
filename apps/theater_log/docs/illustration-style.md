# ゲキポンの挿絵の決まり（ゴム印の線画）

ゲキポンの挿絵は、もぎりのゴム印や切符の小さな記号のような線画で描きます。2026-11-08 にオーナーが 4 つの画風から選びました。描き手が変わっても同じアプリの絵に見えるよう、次の決まりを守ります。

## 決まり

| 項目 | 決まり |
|---|---|
| 色 | 紙・墨・朱の 3 色だけ（`Palette.paper`・`Palette.sumi`・`Palette.vermilion`） |
| 線 | 墨の線 1 種類。120×100 の枠で太さ 2.2。角は立て（miter）、線の端は切りっぱなし（butt） |
| 朱 | 塗りにだけ使い、朱の線は描かない。例外は明かりなどを表す朱の点線 |
| 形 | 直線と円・ゆるい曲線で、図のように整える。正面か真横から描く |
| 題材 | 劇場の道具と場所（幕、客席、提灯、拍子木、半券など） |
| 描かないもの | 人の顔、影、グラデーション、かすれ |

かすれはハンコだけの表現です。挿絵には付けません。挿絵とハンコが同じ画面に並んでも、どれがハンコかがすぐわかるようにするためです。

## 小さく置いたとき

画面に 44px で置いても形がわかることを確かめます。わからない場合は、細部を描き足すのではなく減らします。

## 作り方

- 絵は `lib/widgets/illustrations.dart` に CustomPainter で描き、`LineArt` から置きます。
- 新しい絵は、先に見本ページで実寸の画面に置き、オーナーの OK をもらってからアプリに入れます。

## 使っている場所

| 絵 | 場所 |
|---|---|
| 幕が開く（`LineArt.curtain`） | 半券帳がまだ空のとき |
| 客席（`LineArt.seats`） | 「みんな」に感想がまだ無いとき |
