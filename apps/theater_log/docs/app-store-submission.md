観た舞台を半券にして集める観劇記録アプリ。戯曲図書館のアプリから 2026-11-05 に分離した。サーバー、DB、戯曲 ID、運営画面は戯曲図書館と共通。

| 項目 | 状態 |

| Bundle ID | `com.gikyokutosyokan.theaterlog` |
| ログインの戻り先 | `gikyokutheaterlog://auth-callback`（戯曲 ID の許可リストに登録済み） |
| Firebase のアプリ登録 | 済（`ichinomiya-apps`） |
| アプリの名前 | ゲキポン（ストアの名前は「ゲキポン - 観劇記録スタンプラリー」、サブタイトルは「観た舞台を残して、全国の劇場をめぐる」） |
| ASC のアプリ登録、TestFlight | 済（App ID 6830914655、内部グループ「開発」） |
| ストアの資料 | 未（プライバシー申告と審査メモは下に用意） |

対応端末は iPhone のみ。サーバー側の確認は gikyoku_tosyokan の `scripts/test-app-api.mjs`。

## App のプライバシー（ASC に入れる答え）
アプリの中の `ios/Runner/PrivacyInfo.xcprivacy` と同じ内容にそろえています。トラッキングはしません。

| データの種類 | ユーザーに結び付けるか | 目的 |
|---|---|---|
| 連絡先情報：メールアドレス（戯曲 ID） | する | アプリの機能 |
| 連絡先情報：名前（公開の名前） | する | アプリの機能 |
| ユーザーコンテンツ：その他（作品名、観た日、劇団、劇場、座席、チケット代、評価、感想） | する | アプリの機能 |
| 識別子：ユーザー ID | する | アプリの機能 |
| 使用状況データ：製品の操作（Firebase Analytics） | しない | 分析 |
| 診断：クラッシュデータ（Crashlytics） | しない | アプリの機能 |

写真とチケットの写真は端末の中だけに保存し、送らないので申告しません。ログインしない人の記録も端末の中だけです。

## 審査メモ（App Review への情報）
審査用のアカウントは要りません。ログインしなくても記録できます。ログインは「Appleでサインイン」で試せます。

```
ゲキポンは、観た舞台を記録する観劇ノートです。ログインしなくても記録できます。
・記録：下の「観た！」（初回は「最初の半券を切る」）から。チケットの読み取りは端末の中で行い（iOS 16 以降）、画像は送信しません。
・ログイン：アカウント（右上の人のアイコン）から「Appleでサインイン」。ログインすると記録を同期し、感想を公開できます。
・感想の公開：記録の編集で「感想をみんなに公開する」をオン。初回に利用規約とプライバシーポリシーへの同意を求めます。
・通報とブロック：「みんな」タブの各感想の「…」から。通報は運営に通知され、24 時間以内に確認します。2 人から通報された感想は自動で非公開になり、運営は投稿者の公開を止められます。
・アカウントの削除：アカウント画面の「アカウントを削除」から、戯曲 ID の削除ページへ直接移ります。観劇の記録と公開した感想も消えます。
・劇場スタンプは、このアプリの楽しみ方で、各劇場とは関係ありません。
```
