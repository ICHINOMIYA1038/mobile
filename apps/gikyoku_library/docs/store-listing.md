## 説明
上演する台本選びを助けるアプリです。戯曲図書館に載っている作品を、人数と上演時間から探せます。

■ 条件で探す
・登場人数（1人、2人、3〜5人、6〜10人、11人以上）
・上演時間（30分まで、60分まで、90分まで、91分以上）
・ジャンル（コメディ、感動、学校など）
・台本の掲載先があるか
・作品名と作者名

■ 作品を確かめる
人数の内訳、上演時間、賞、上演した劇団、台本の掲載先をまとめて見られます。

■ 候補を比べて共有する
気になる作品を候補に集めると、人数と時間を一覧で比べられます。候補はリンクつきで部員や劇団の仲間に送れます。

■ 電波がなくても使える
作品の情報を端末に持つので、稽古場や学校でもすぐに探せます。ログインは要りません。

演劇部の台本選び、文化祭の劇、学生劇団や社会人劇団の次回公演に使えます。

※人数や上演時間が不明の作品もあります。上演するときは、台本の内容と上演の条件を作者や権利者に確かめてください。
