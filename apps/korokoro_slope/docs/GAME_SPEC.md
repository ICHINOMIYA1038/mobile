# コロコロスロープ ゲーム仕様書

最終更新: 2026-07-31 / ステータス: **確定（Phase 1方針）**

## 0. 目的・方針転換の経緯

現状は「動くプロトタイプ」（傾き操作でボールを転がす手続き生成の坂道エンドレスゲーム、Flutter+WebView(three.js/cannon-es)実装）。

当初「基本無料＋IAP」でのマネタイズ強化を検討したが、**まずは既存の広告収益(AdMob)のみで運用し、人気が出てから課金要素を検討する** 方針に変更した。それまでの期間は **ゲームとしての品質（ビジュアル・ゲーム性・UI/UX）を上げることに集中** する。IAP関連の検討内容は「Phase 2（保留）」として本書末尾に残す。

## 1. コンセプト

- ジャンル: 傾き操作の坂道転がりアクション（カジュアル・エンドレスダウンヒル）
- ワンフレーズ: 「傾けて転がす、リラックス系スロープダッシュ」
- コア体験: 端末を傾けるだけの直感操作、短時間で1プレイ完結、繰り返し遊んでベスト記録更新・コレクション収集を狙う
- 参考ジャンル感: Alto's Odyssey / Subway Surfers 系のカジュアルエンドレス + コレクション

## 2. ターゲット/ポジショニング

- 想定ユーザー: スキマ時間にライトに遊びたい層。全年齢対象（過度な暴力・恐怖表現なし）
- 配信優先度: iOS (App Store) を優先。Android(Google Play)は同一コードベースのため後追いで並行対応可能
- **収益モデル: Phase 1は広告収益のみ**（既存`AdService`のインタースティシャル＋リワード、バナーなし方針を維持）。IAPは人気の兆し（DL数/継続率などの実績）が見えてから検討する。

## 3. Phase 1 でやること（今ここ）

「品質を上げる」を、以下3領域の実装として進める。

### 3.1 ビジュアル/アセット強化
- 影・グラデーション空・ボール/路面のテクスチャ・パーティクル演出（ダストトレイル/コイン取得/着地）
- 追加コーステーマ（岩場・雪原など）用に、フリー(CC0中心)3Dアセットを新規調達
- 詳細な実装項目は `/Users/ichinomiya/.claude/plans/sharded-noodling-crab.md` の技術計画を参照（本仕様のPhase 1範囲に合わせて更新して使う）

### 3.2 ゲーム性の拡張
- ブーストパッドなど新規セグメント種別
- ボールスキンのコイン解放（IAP不要、既存`totalCoins`のみで完結）
- コーステーマ切り替え（岩場・雪原など、6章のアセット体制で調達したモデルを使用）

### 3.3 UI/UXの仕上げ
- タイトル/結果画面の演出強化、初回チュートリアルヒント、スキン選択UI

これらはすべて **既存のセーブスキーマ(`bestScore`/`totalCoins`)・既存広告フローの範囲内** で実現し、IAP・ジェム通貨・ストア画面・ATT対応などPhase 2向けの実装は行わない。

## 4. コアゲームループ（変更なし）

1. タイトル → タップでスタート
2. 坂を転がりながら左右ステアでコース維持、コイン収集
3. コースアウト/落下でラン終了 → リザルト（距離・コイン・スコア）
4. コンティニュー(リワード広告) or リトライ or タイトルへ

## 5. 非機能要件（Phase 1時点）

- パフォーマンス目標: 中位端末で60fps維持、WebView初回ロード時間の最適化
- オフライン: コアゲームプレイはオフラインで完結。広告表示のみオンライン必須
- AdMob本番広告ユニットID: 現状テストIDのまま（`lib/data/ad_service.dart`）。ストア申請前に必須対応（Phase 1後期のタスク）

## 6. フリーアセット調達・管理体制

継続的にフリー素材（3Dモデル・テクスチャ・音声等）を調達して使えるように、以下の体制を整備する。

### 6.1 ディレクトリ構成
- `asset_library/` — 調達した素材の**ソース置き場**（zip展開後の生データ、ライセンス文書込み）。ゲームに実際に使うかどうかに関わらず、将来使えそうな素材はここにストックする。
  - `asset_library/models/<pack-name>/` — 3Dモデルパック単位
  - `asset_library/audio/<pack-name>/` — 効果音・BGMパック単位
  - `asset_library/textures/<pack-name>/` — テクスチャ/UI素材パック単位
  - `asset_library/MANIFEST.md` — 調達した全パックの一覧（出典URL・ライセンス・用途メモ）
- `web_game/static/` — **実際にゲームに組み込み済み**の素材のみを置く既存の場所（`asset_library/`から必要な分だけコピーして使う）

### 6.2 素材選定ポリシー
- **CC0（パブリックドメイン相当）を最優先**。既存素材（Kenney, OpenGameArt由来）と同じ扱い方針を継続。
- CC0以外（CC-BYなど表記必須のもの）を使う場合は`MANIFEST.md`とパックごとのCREDITSに出典・ライセンス・必要なクレジット文を明記する。
- 出典として信頼できる配布元を優先: Kenney.nl（既存実績あり、glTF形式で配布されており`generate_model_data.js`にそのまま組み込みやすい）、OpenGameArt.org（既存BGMの出典）、Poly Pizza / Quaternius（CC0低ポリ3Dモデル）、Freesound.org（CC0音源、要フィルタ）。
- 既存の絵柄（ローポリ・カートゥーン調、Kenney Mini Forestに近いトーン）と統一感のあるものを選ぶ。

### 6.3 ゲームへの組み込み手順（3Dモデルの場合）
1. `asset_library/models/<pack-name>/` に展開・保管
2. 使うモデルだけ `web_game/static/models/` にコピー
3. `web_game/generate_model_data.js` の `MODEL_NAMES` に追加
4. `npm run build`（`generate_model_data.js`実行→Base64埋め込み）
5. `web_game/MODEL_CREDITS.md` に出典を追記

## 7. Phase 2（保留・人気が出てから検討）

以下は「基本無料＋IAP」化を検討する際のドラフト。人気の兆しが見えた時点でこの章をベースに再設計する。

- **収益モデル**: 基本無料＋IAP。広告除去(¥370・非消耗型)、ジェムパック小/中/大(¥120/¥370/¥980)、スターターパック(¥250)。広告除去購入者はコンティニュー機能自体を非表示にする。
- **プレミアム通貨「ジェム」**: IAP購入 or 実績/チャレンジ報酬で入手。コインだけでも主要コンテンツに到達できるフェアさを維持しつつ時短/特別感を売る。
- **チャレンジコース**: シード固定の専用ロングコースを2本(初級/上級)、クリア評価と報酬。
- **ミッション/実績システム**: 累計距離/コイン等の達成報酬。
- **追加UI**: モード選択、ストア画面、実績一覧。
- **技術**: `in_app_purchase`導入・App Store Connect側の商品登録、`app_tracking_transparency`導入によるATT対応（パーソナライズ広告有効化）、`SaveService`/`GameBridge`のスキーマ拡張（ジェム・実績進捗）。
